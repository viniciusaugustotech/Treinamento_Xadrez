#Projeto_Xadrez

TEMA: Treinamento

PROJETO: Site de Treinamento em Xadrez

NOME: Passo de Mestre

OBJETIVO: Desenvolver um software que contenha táticas de xadrez e ofereça cursos para treinamento em xadrez

Escopo do Sistema:

Requisitos funcionais:

RF01 - O sistema deve permitir o cadastro e autenticação de usuários;
RF02 - O sistema deve disponibilizar que os usuários visualizem os cursos disponíveis;
RF03 - O sistema deve verificar as respostas do quiz inicial quando o usuário tiver cadastrado;
RF04 - O sistema deve permitir o acampanhamento das estatísticas e progresso do curso;
RF05 - O sistema deve registrar o progresso do usuário nos cursos;
RF07 - O sistema deve disponibilizar card que descrevam o movimento das peças de xadrez;
RF08 - O sistema deve recomendar treinamentos com base no desempenho registrado;
RF09 - O sistema deve permitir que o usuário pesquise cursos e treinamentos disponíveis;
RF10 - O sistema deve disponibilizar aulas organizadas por curso e módulo;
RF11 - O sistema deve permitir que que o usuário altere as informações da conta;
RF12 - O sistema deve exibir as informações do curso selecionado quando o usuário clicar;
RF13 - O sistema deve verificar a autenticidade e as permissões do usuário (administrador ou usuário);
